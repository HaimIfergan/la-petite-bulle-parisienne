## 📌 À propos du projet

**La Petite Bulle Parisienne** est un prototype / site vitrine  imaginé pour une **librairie indépendante et chic** située au cœur de Paris. 

L'objectif de cette application web est de proposer une vitrine élégante, chaleureuse et raffinée pour une librairie de quartier :
- 📖 Présentation des sélections littéraires et coups de cœur des libraires.
- ☕ Découverte de l'espace salon de thé et des événements culturels (dédicaces, clubs de lecture).
- 📍 Informations pratiques (horaires, accès, contact).

---

## 🛠️ Stack Technique & Outils

- **Frontend :** React, Vite, Tailwind CSS
- **Composants & Design :** UI moderne, réactive et élégante avec Lucide Icons
- **Prototypage & Sync :** Développé et synchronisé via **Lovable**
- **Gestion de code & Déploiement :** GitHub (branche `main`)

---

## 🚀 Fonctionnalités principales

- 📱 Design élégant, épuré et optimisé pour mobile (*Mobile-First*)
- 📖 Vitrine de présentation littéraire et ambiance de quartier
- ⚡ Interface ultra-fluide et chargement rapide
- 🔄 Synchronisation automatique du code entre Lovable et GitHub
